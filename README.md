A deterministic Python program that writes one line of software error copy — at most 200 characters, telling the user the brutal truth about what went wrong and making them laugh — to /output/entry.txt. The line confesses the disk is full because we kept every log since 2019 and deleted nothing — so the user's file is the first thing we've ever thrown away.

## Run it

```sh
python3 main.py
```
